输入与本机学习

Rectfly 键盘扩展不联网。中文纠错、英文补全、词语联想和个人学习在设备上完成。输入文字、导入的 Rime 用户词库及学习记录只在本机使用，不上传到我们的服务器，也不在设备间同步。

我们不收集键盘输入内容。首次提示选“好”或之后在设置打开评测，即同意主 App 在满 500 次对比后、处于前台时自动发送不关联身份的评测统计，具体内容见下方说明。App 无第三方 SDK、无广告、无追踪工具。本机学习会使用你的选词和输入习惯；这不表示把输入内容发送给开发者。

本机评测记录与诊断日志

从公开版 0.1（322）起，本机评测开启时，键盘会在本机保存评测所需的输入重放记录。新版新安装首次打开 App，在语法下载引导后询问是否帮助改进 Rectfly。选“好”开启本机评测和自动发送，选“不用了”保持关闭；选择前不采集评测记录、不自动发送。升级用户保留原评测开关状态。键盘在主 App 同步开启设置后开始采集，可在主 App 关闭。记录可能包含输入文字、候选、触点和周边上下文，验证码等普通输入框的内容也可能被记录。原始记录不上传，也不提供查看或导出。

关闭“本机评测”会停止采集，但不会删除已有输入记录；可在“隐私与数据”中通过“清除本机评测记录”删除。“清除学习记录”单独重置本机学习。

较早的公开版及内部测试版提供可选的输入日志和故障包导出，默认关闭。启用后可在“隐私与数据”管理记录，并通过长按键盘“123”保存故障包供手动分享。故障包可能包含文字与上下文，发送前请检查并移除私人内容。新版公开版不提供这些诊断导出入口。

为什么请求完全访问

Rectfly 键盘扩展声明请求“允许完全访问”。它用于键盘与主 App 在本机共享设置、按键震动级别、用户词库、已下载语法模型及个人学习数据，也用于共享本机评测记录，以及在键盘显示时读取普通剪贴板文字并在本机保存剪贴板历史；内部及较早版本还支持可选日志和手动故障包导出。

完全访问会扩大 iOS 授予键盘的权限，包括联网能力；Rectfly 键盘不使用该能力发送输入。基础输入可不授予完全访问，但本机共享与相关功能可能受限。你可随时在 iOS 设置中关闭它。查看操作方法。

剪贴板历史

快速粘贴和剪贴板历史默认关闭，需要你在键盘里确认开启或在主 App 设置中打开；两项都关闭时键盘不读取剪贴板。开启并授予完全访问后，键盘显示期间检测到新的复制时会读取普通剪贴板文字，系统可能显示粘贴提示。历史仅存于本机 App Group，不上传、不同步，并排除系统备份。最多保存 50 条，保存时长可选 10 分钟、1 小时、7 天（默认）或 3 个月；下次读取时清理过期项。你可以单条删除、全部清空，关闭历史时已保存的内容会被删除。

带 Concealed / Transient 标记的内容不会收录；iOS 不公开来源过期时间，因此不能保证识别所有密码或临时文字。空白或超过 16 KiB 的文字也不会收录。快速粘贴提示在首次检测到新副本后三分钟内显示，使用、关闭或开始输入后收起；历史支持整段粘贴或滑动选词。

iCloud 同步设置

主 App 默认通过你的 iCloud 账户同步键盘设置，例如双拼方案、中文输出、按键震动、拼音显示位置、词包开关和强调色，让同一 Apple 账户下的设备使用相同设置。这些数据由 Apple 的 iCloud 保存，我们无法访问。输入内容、剪贴板、学习记录、用户词库和评测记录不参与同步。自定义键盘图标的照片只在本机裁切成小图保存，不上传、不同步。你可以在设置中关闭「用 iCloud 同步设置」。

键盘离线，主 App 可下载语法和发送统计

键盘扩展的输入过程不使用网络。主 App 的“万象语法”功能会在启动时查询 GitHub 的公开发布接口以检查模型更新，也可由你手动检查；模型文件仅在你选择下载或更新后获取。模型安装后由键盘离线读取，你也可以在主 App 中删除模型。

这些请求不附带你的输入、用户词库、学习记录或输入日志。GitHub 及下载服务会接收到建立网络连接所需的 IP 地址和请求信息，并按其服务规则处理。首次提示选“好”或之后在设置打开评测，即同意主 App 在满 500 次对比后、处于前台时自动发送评测统计，说明如下；键盘输入内容不会随统计上传。

联邦评测与自愿分享

联邦评测使用已有的本机输入记录，将最多三个试验组分别与当前方案对比，计算在本机完成，不改变当前键盘。统计衡量首选候选与实际上屏选词是否一致，不代表输入正确率。

新版首次提示选“好”或之后在设置打开评测，即同意满 500 次对比后，在 App 前台自动发送统计，无需逐次确认。升级前已开启评测者也会被询问一次是否自动发送；选“不用了”或未选择时，评测保持开启，仍可手动发送。升级前已关闭者保持关闭。提示只问一次，之后通过设置开关调整。

你可在评测结果中打开“查看统计内容”；保留手动发送的用户可点击“发送统计结果”。主 App 将统计通过 HTTPS 发送到 Rectfly 使用的 Cloudflare Workers 服务，保存在 Cloudflare D1 数据库，用于分析和改进输入算法。无需邮件，也无需注册或登录。旧版仍通过邮件或系统分享面板发送。

发送内容只有汇总计数和必要标识：包括“两种都一致、仅当前一致、仅试验一致、两种都不一致”的计数、总数和按输入长度分组的统计，以及实验与试验组标识、构建版本标识、完成日期和随机提交编号。编号只用于防止同一轮重复计数，不是设备标识；不含输入文字、所选词语、拼音或按键记录。评测统计与可能含文字的故障包是不同文件。

每个实验只发送首次授权入队的那份结果，包括已授权自动发送的结果。发送失败时，App 会保留待发送统计，并在 App 前台重试。关闭“本机评测”会取消待发送任务并清除评测结果文件，原始输入记录需单独清除；已经接收的统计不会因此从服务器撤回。

Cloudflare 为传输和防滥用处理 IP 地址等连接信息。我们的评测数据库不保存 IP 地址、设备标识或输入日志，不将统计用于广告或跨应用追踪。统计保留至管理员删除。如需咨询或请求删除，请联系 rectfly@fastmail.com；由于结果不关联账号或身份，我们可能需要相应的提交编号才能定位记录。

本网站与联系

本网站仅使用静态 HTML、CSS 和本地图片，无脚本、无 Cookie、无追踪、无外部字体或第三方嵌入。外部来源链接仅在你点击时打开。

网站由 GitHub Pages 托管，访问时托管服务可能处理 IP 地址等必要请求信息。网站不收集你的键盘输入。

隐私问题或数据处理咨询，请联系 rectfly@fastmail.com。你主动发送的邮件内容会交由邮件服务处理，请避免附带敏感输入记录。

Privacy policy · English

Updated October 27, 2026

Typing and local learning

The Rectfly keyboard extension does not access the network. Correction, completion, suggestions and personal learning run on your device. Typed text, imported Rime user dictionaries and learning records stay local; they are not uploaded or synced between devices. We do not collect keyboard input content. Choosing OK in the first prompt or later enabling evaluation in Settings consents to automatic uploads of evaluation statistics after 500 comparisons while the app is in the foreground. These statistics are not linked to your identity, as described below. There are no third-party SDKs, ads or tracking tools.

Local evaluation records and diagnostic logs

Starting with public build 0.1 (322), the keyboard stores local input replay records while on-device evaluation is enabled. On first launch of a new installation of the updated app, after grammar download onboarding, Rectfly asks whether to help improve the app. Choosing OK enables local evaluation and automatic aggregate uploads; choosing No Thanks leaves evaluation off. No evaluation records are collected or automatically sent before this choice. Upgraded users retain their evaluation setting. Keyboard collection starts after the main app synchronizes the enabled setting; evaluation can be disabled in the main app. Records may contain text, candidates, touch events and surrounding context, including verification codes entered into ordinary fields. Raw records are not uploaded and cannot be viewed or exported through the public app.

Disabling evaluation stops collection but does not delete existing input records. Use Clear Local Evaluation Records under Privacy & Data to delete them. Local learning can be reset separately.

Earlier public builds and internal builds offer optional input logging and fault export, disabled by default. When enabled, long-pressing “123” saves a recent fault bundle for manual sharing. Bundles may contain text and context; review them and remove private information before sharing. These diagnostic export controls are not available in the updated public build.

Full Access

The extension requests Full Access for local sharing of settings, haptic preferences, imported dictionaries, installed grammar models and personal learning between the app and keyboard, as well as local evaluation records. It also permits reading ordinary clipboard text when the keyboard appears and storing clipboard history locally. Internal and earlier builds also support optional logs and manual fault export. iOS also grants network capability with this permission; Rectfly's keyboard does not use it to send your input. Basic typing works without Full Access, while shared features may be limited. You may revoke it in iOS Settings at any time.

Clipboard history

Quick paste and clipboard history are off by default; you turn them on from the keyboard's prompt or in the app's settings. With both off, the keyboard does not read the clipboard. When enabled with Full Access, ordinary clipboard text is read when a new copy is detected while the keyboard is shown, and the system may display a paste notification. History stays in the local App Group, without upload or sync, and is excluded from system backups. Up to 50 entries are kept for 10 minutes, 1 hour, 7 days (default) or 3 months, as you choose; expired entries are removed on the next read. You can delete entries individually or clear all, and turning history off deletes what was kept.

iCloud settings sync

By default the app syncs keyboard settings, such as the Shuangpin scheme, Chinese output, haptics, pinyin position, pack toggles and accent color, through your iCloud account so devices on the same Apple Account share them. Apple stores this data in iCloud; we cannot access it. Typed text, clipboard, learning records, imported dictionaries and evaluation records are not synced. A custom keyboard logo photo is cropped to a small image and kept on the device only; it is not uploaded or synced. You can turn off “Sync settings with iCloud” in Settings.

Content marked Concealed or Transient is skipped. iOS does not expose the source expiration date, so not all passwords or temporary text can be identified. Blank text and text exceeding 16 KiB are also skipped. The quick-paste offer lasts up to three minutes after a new copy is first observed, or until dismissed, used or typing begins. History supports pasting whole entries or selecting words by sliding.

Grammar downloads

The main app checks GitHub's public release API for grammar updates at launch or when you request a check. It downloads model files only when you choose to download or update them. Installed models are used offline and can be deleted in the app. Requests do not include typed text, dictionaries, learning records or input logs. GitHub and download services receive connection information such as your IP address. Choosing OK in the first prompt or later enabling evaluation in Settings consents to automatic aggregate uploads after 500 comparisons while the app is in the foreground, as described below; these uploads do not include keyboard input content.

Federated evaluation

Evaluation uses existing local input records to compare up to three trial groups individually against the current configuration. It runs on your device and does not change the current keyboard. Counts measure whether the top candidate matches the word actually committed, not typing accuracy.

Choosing OK in the updated app's first prompt or later enabling evaluation in Settings consents to automatic aggregate uploads after 500 comparisons while the app is in the foreground, without confirming each upload. Users who had evaluation enabled before upgrading are also asked once about automatic sending. If they choose No Thanks or leave the prompt unanswered, evaluation stays enabled with manual sending. Users who had evaluation disabled keep it off. The prompt is shown only once; later changes use the Settings switch.

You can open View Statistics in the evaluation results; users retaining manual sending can tap Send Statistics. The main app uploads statistics over HTTPS to Rectfly's Cloudflare Workers service, where Cloudflare D1 stores them for analysis and improvement of the input algorithms. No email, account or sign-in is required. Older versions use email or the system share sheet.

The payload contains only aggregate counts and necessary identifiers: counts where both configurations match the committed word, only the current configuration matches, only the trial matches, or neither matches; totals and input-length buckets; experiment, trial group and build identifiers; a completion date; and a random submission ID for deduplication. This ID identifies one experiment submission, not a device. It contains no typed text, selected words, pinyin or key events. Fault bundles are separate and may contain text.

Only the first snapshot queued with your authorization per experiment is submitted, including results covered by automatic-upload consent. Failed uploads remain in a local outbox and retry while the app is in the foreground. Disabling evaluation cancels pending uploads and clears evaluation result files. Raw input records must be deleted separately. Cancellation does not recall statistics already received by the server.

Cloudflare processes connection information such as IP addresses for transport and abuse prevention. Our evaluation database stores no IP addresses, device identifiers or input logs. The statistics are not used for advertising or cross-app tracking and remain stored until an administrator deletes them. Contact rectfly@fastmail.com for questions or deletion requests. Because results are not linked to accounts or identities, we may need the relevant submission ID to locate a record.

Website and contact

This static website uses local images and CSS, with no scripts, cookies, analytics, external fonts or third-party embeds. External links open only when selected. The host, GitHub Pages, may process IP addresses and other request information needed to serve pages. Contact rectfly@fastmail.com about privacy. Messages you choose to send are handled by email services; avoid including sensitive input records.
