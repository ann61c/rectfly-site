输入与本机学习

Rectfly 键盘扩展不联网。中文纠错、英文补全、词语联想和个人学习在设备上完成。输入文字、导入的 Rime 用户词库及学习记录只在本机使用，不上传到我们的服务器，也不在设备间同步。

我们不通过 Rectfly 收集个人信息。App 无第三方 SDK、无广告、无追踪工具。本机学习会使用你的选词和输入习惯；这不表示把输入内容发送给开发者。

输入日志默认关闭

公开版默认不记录输入日志。只有你在 App 的“隐私与数据”中打开“记录输入日志”后，才会把排查输入问题所需的日志写入本机。日志可能包含输入文字、候选、触点和周边上下文，验证码等普通输入框的内容也可能被记录。

你可以随时关闭记录，并通过“清除输入日志”删除已有日志。“清除学习记录”单独重置本机学习。关闭记录不等于删除已有日志。

“启用键盘内导出”是另一个可选开关。开启后，长按键盘的“123”可保存近期故障包，再由主 App 手动分享。故障包可能包含文字与上下文，发送前请检查并移除私人内容。

为什么请求完全访问

Rectfly 键盘扩展声明请求“允许完全访问”。它用于键盘与主 App 在本机共享设置、按键震动级别、用户词库、已下载语法模型及个人学习数据，也用于可选日志和手动故障包导出。

完全访问会扩大 iOS 授予键盘的权限，包括联网能力；Rectfly 键盘不使用该能力发送输入。基础输入可不授予完全访问，但本机共享与相关功能可能受限。你可随时在 iOS 设置中关闭它。查看操作方法。

键盘离线，主 App 可下载语法

键盘扩展的输入过程不使用网络。主 App 的“万象语法”功能会在启动时查询 GitHub 的公开发布接口以检查模型更新，也可由你手动检查；模型文件仅在你选择下载或更新后获取。模型安装后由键盘离线读取，你也可以在主 App 中删除模型。

这些请求不附带你的输入、用户词库、学习记录或输入日志。GitHub 及下载服务会接收到建立网络连接所需的 IP 地址和请求信息，并按其服务规则处理。Rectfly 没有用于接收输入或评测结果的自建服务器。

联邦评测与自愿分享

联邦评测使用已有的本机输入记录，对比现版与候选新版的结果，计算过程与结果留在本机。你可在 App 内关闭评测。

你点击“分享”后，App 会打开预填好的邮件，收件人为 rectfly@fastmail.com，并附上评测统计文件。你可以检查邮件和附件，再自己点击“发送”，也可以取消。未配置邮件时，App 会退回系统分享面板，由你选择如何分享。Rectfly 没有接收评测结果的服务器，不会自动发送。

导出内容包括“两版都对、只有现版对、只有新版对、两版都错”等计数、总数和按输入长度分组的统计，以及实验标识、构建版本标识和完成日期；不含输入文字、所选词语、拼音或按键记录。评测统计与可能含文字的故障包是不同文件。

本网站与联系

本网站仅使用静态 HTML、CSS 和本地图片，无脚本、无 Cookie、无追踪、无外部字体或第三方嵌入。外部来源链接仅在你点击时打开。

网站计划由 GitHub Pages 托管，访问时托管服务可能处理 IP 地址等必要请求信息。网站不收集你的键盘输入。

隐私问题或数据处理咨询，请联系 rectfly@fastmail.com。你主动发送的邮件内容会交由邮件服务处理，请避免附带敏感输入记录。

Privacy policy · English

Updated October 22, 2026 · Pre-release draft

This draft describes the intended public release: input logging is off by default and evaluation statistics are sent by the user via email, with the system share sheet as a fallback when email is not configured. It takes effect after those behaviors have been verified in the public build.

Typing and local learning

The Rectfly keyboard extension does not access the network. Correction, completion, suggestions and personal learning run on your device. Typed text, imported Rime user dictionaries and learning records stay local; they are not uploaded or synced between devices. We do not collect personal information through Rectfly. There are no third-party SDKs, ads or tracking tools.

Optional logs and fault bundles

Input logging is off by default in the public release. If you enable it under Privacy & Data, logs are stored locally and may contain text, candidates, touch events and surrounding context, including verification codes entered into ordinary fields. You can disable logging and delete existing logs separately. Local learning can be reset separately. Turning logging off does not delete existing files.

Keyboard fault capture is a separate option. When enabled, long-pressing “123” saves a recent fault bundle for manual sharing from the app. Bundles may contain text and context. Review them and remove private information before sharing.

Full Access

The extension requests Full Access for local sharing of settings, haptic preferences, imported dictionaries, installed grammar models and personal learning between the app and keyboard, as well as optional logs and manual fault export. iOS also grants network capability with this permission; Rectfly's keyboard does not use it to send your input. Basic typing works without Full Access, while shared features may be limited. You may revoke it in iOS Settings at any time.

Grammar downloads

The main app checks GitHub's public release API for grammar updates at launch or when you request a check. It downloads model files only when you choose to download or update them. Installed models are used offline and can be deleted in the app. Requests do not include typed text, dictionaries, learning records or input logs. GitHub and download services receive connection information such as your IP address. Rectfly operates no server to receive input or evaluation results.

Federated evaluation

Evaluation compares versions using existing local input records. Processing and results remain on your device, and evaluation can be disabled. When you tap Share, the app opens a prefilled email addressed to rectfly@fastmail.com with the statistics file attached. You can review the message and attachment, then tap Send yourself, or cancel. If email is not configured, the app falls back to the system share sheet so you can choose how to share. Rectfly has no server receiving evaluation results and never sends them automatically. The export contains win/loss counts, totals, input-length buckets, experiment and build identifiers, and a completion date. It contains no typed text, selected words, pinyin or key events. Fault bundles are separate and may contain text.

Website and contact

This static website uses local images and CSS, with no scripts, cookies, analytics, external fonts or third-party embeds. External links open only when selected. The intended host, GitHub Pages, may process IP addresses and other request information needed to serve pages. Contact rectfly@fastmail.com about privacy. Messages you choose to send are handled by email services; avoid including sensitive input records.
